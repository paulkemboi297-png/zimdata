# ZimData Homepage

This is a mobile-first starter homepage for a Zimbabwe data-bundle store.

Files:
- index.html
- style.css
- script.js

Important:
- Package prices in script.js are illustrative starter prices and should be replaced with your actual prices.
- The current version does not process real payments or send orders to a server.
- Never collect or transmit an EcoCash PIN.
- The next stage can connect the order form to a backend and Telegram admin notifications using only safe order/payment-reference data.
